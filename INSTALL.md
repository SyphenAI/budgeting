# Install guide

On **Windows**, use Docker Desktop. Full steps are in **[README.md](README.md)**.

| Step | What to run |
|------|-------------|
| Install and start Docker Desktop | Wait until it says it is running |
| Start the app | Right-click `docker-start.bat` → **Run as administrator** |
| Stop the app | Double-click `docker-stop.bat` |
| First sign-in | `admin` / `admin`, then choose your own password |

On this computer: **http://127.0.0.1:50100**  
On another device on the same home network: **http://THIS-COMPUTER-192-ADDRESS:50100** (printed by `docker-start.bat`)

Later updates: sign in → **Household** → **App updates** → **Check for a newer version** → **Update now**.

Forgot password: use the rescue code from Household. That does **not** erase the budget.
