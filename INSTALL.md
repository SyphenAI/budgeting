# Install guide

You do not need to know Docker. Full pictures-in-words steps are in **[README.md](README.md)**.

**Short version (Windows):**

1. Install [Docker Desktop](https://www.docker.com/products/docker-desktop/) and open it until it says it is running.
2. Right-click **`docker-start.bat`** → **Run as administrator**.
3. Browser: **http://127.0.0.1:50100**
4. Sign in **`admin` / `admin`**, then pick your own password. Write down the rescue code.

Stop: double-click **`docker-stop.bat`**.

Phone on the same Wi‑Fi: use the `http://192.…:50100` line printed in the start window.

Updates: **Household** → **App updates** → **Check** → **Update now**.

Forgot password: rescue code on the sign-in page. That does not erase the budget.
