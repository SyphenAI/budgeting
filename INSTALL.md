# Install guide

For first-time users on **Windows**, follow the main instructions here:

**→ [README.md](README.md)**

That guide is written for people who have never used a command line.

### Quick reminder

| Step | What to run |
|------|-------------|
| First time only | Right-click `install.bat` → **Run as administrator** |
| Every time you use the app | Right-click `start.bat` → **Run as administrator** |
| First sign-in | username `admin` / password `admin` (then create your own password) |

App address in the browser: **http://127.0.0.1:8787**

### Windows Defender

Many PCs block `.bat` files until you allow them. Use **Run as administrator**, or **More info → Run anyway** on SmartScreen. Details are in the README section **“Windows Defender / blocked messages”**.

### Updates later

Right-click **`update.bat`** → **Run as administrator**.  
That pulls the latest app from GitHub and **keeps your data folder**. See README → **Getting a newer version**.
